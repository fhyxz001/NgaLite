## 设置页新增「服务器域名」配置项 + 图片域名切换

- 新增 `data/BaseConfig.kt`：可配置域名列表 `bbs.nga.cn / nga.178.com / ngabbs.com`（存 `nga_prefs` 的 `base_domain` 键），提供 `domain()` / `setDomain()` / `baseUrl`。

- 其余硬编码 `bbs.nga.cn` 全部改为 `BaseConfig.baseUrl`：NgaParser（相对路径补全）、ExportManager（Referer + 两处 loadDataWithBaseURL）、DetailScreen（postUrl + 分页请求）、LoginWebScreen（LOGIN_URL/BASE_URL 改 getter）。
- 图片/表情域名 `img.nga.178.com` → `img.nga.cn`：UbbParser.IMG_BASE、NgaParser.normalizeImageUrl、ExportManager 两处 emoji 渲染。
- SettingsScreen「通用」分组新增「服务器域名」下拉（DropdownMenu），切换时自动 `CookieStore.clear()`（跨域 Cookie 不通用）。
- 验证：`gradlew.bat :app:compileDebugKotlin` 通过。

## 环境备忘

- 该项目部分 .kt 文件被 Read 工具误判为 binary（含 CRLF），读取/编辑需先 cp 到 build/tmp 镜像目录操作再拷回。
- gradlew 在 Git Bash 下报 cygpath 错误，须用 PowerShell 运行 `.\gradlew.bat`。
- 临时文件删除时 safe-delete 会拦截批量删除（>50 文件），需分批或先 escalation。
